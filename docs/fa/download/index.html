دریافت روزنما

یک بار دریافت کن،
هر روز همراهت باشد.

نسخه فعلی روزنما برای ویندوز ۳۲ و ۶۴ بیتی منتشر می‌شود. همه بسته‌ها self-contained هستند و به نصب جداگانه .NET نیاز ندارند. روزنما در نسخه‌های اخیر از Velopack برای سازوکار به‌روزرسانی سبک برنامه استفاده می‌کند.

آخرین انتشار: v0.10.0

اگر مطمئن نیستی کدام معماری را انتخاب کنی، در بیشتر رایانه‌های امروزی ویندوز ۶۴ بیتی نصب است. برای بررسی نسخه و فایل‌ها، صفحه همه انتشارها در GitHub را ببین.

کدام نوع دریافت مناسب‌تر است؟

  • نصبی: انتخاب مناسب برای استفاده معمول؛ نصب‌کننده به‌صورت پیش‌فرض برای حساب کاربری جاری نصب می‌کند.
  • پرتابل: مناسب اجرای برنامه از پوشه دلخواه یا حافظه قابل حمل؛ تنظیمات و گزارش‌ها کنار فایل برنامه ذخیره می‌شوند.
  • پیش‌نیاز: بسته‌ها self-contained هستند و به نصب جداگانه .NET یا Windows App SDK نیاز ندارند.
  • به‌روزرسانی: نسخه‌های اخیر از Velopack برای به‌روزرسانی سبک برنامه استفاده می‌کنند.
