اطلاعات تو،
برای خودت می‌ماند.

روروزنمازمنا برای کارکرد روزمره به اینترنت نیاز ندارد و هیچ داده آماری یا اطلاعات شخصی از کاربران جمع‌آوری نمی‌کند.

جمع‌آوری اطلاعات

روزنما هیچ اطلاعات شخصی، داده آماری، رفتار استفاده یا گزارش تحلیلی از کاربران جمع‌آوری یا ارسال نمی‌کند.

اتصال به اینترنت

برای استفاده عادی از تقویم، مبدل تاریخ و مناسبت‌های همراه برنامه نیازی به اتصال اینترنت نیست. برنامه فقط برای بررسی وجود نسخه جدید می‌تواند به اینترنت و سرویس انتشار GitHub متصل شود. بررسی خودکار به‌روزرسانی از تنظیمات برنامه قابل غیرفعال‌کردن است و امکان بررسی دستی نیز در برنامه وجود دارد.

فایل‌های محلی

تنظیمات و گزارش‌های تشخیصی برنامه به‌صورت محلی روی دستگاه ذخیره می‌شوند. در حالت نصب‌شده، مسیر داده‌ها در پوشه AppData کاربر و در حالت پرتابل، در پوشه data کنار برنامه است. این فایل‌ها به‌صورت خودکار برای سازنده ارسال نمی‌شوند.

سرویس‌های شخص ثالث

در صورت فعال بودن بررسی به‌روزرسانی، درخواست دریافت اطلاعات آخرین انتشار به GitHub ارسال می‌شود. این ارتباط تابع سیاست‌ها و حریم خصوصی GitHub است؛ روزنما داده آماری یا اطلاعات شخصی را به این درخواست اضافه نمی‌کند.

تغییرات این سیاست

اگر رفتار شبکه‌ای یا شیوه نگهداری داده‌ها در نسخه‌های آینده تغییر کند، این صفحه به‌روزرسانی خواهد شد.
