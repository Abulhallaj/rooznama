پرسش‌های متداول

پاسخ چند سؤال،
پیش از شروع.

اگر پاسخ موردنظرت را پیدا نکردی، از بخش Issues مخزن GitHub سؤال یا پیشنهادت را ثبت کن.

آیا روزنما رایگان است؟

بله. روزنما رایگان و متن‌باز است و با مجوز MIT منتشر می‌شود. برنامه‌ای برای عرضه نسخه تجاری یا پولی در نظر گرفته نشده است.

آیا برای کارکرد روزمره به اینترنت نیاز دارد؟

خیر. تقویم، مبدل تاریخ و داده‌های مناسبت همراه برنامه به‌صورت آفلاین کار می‌کنند. اینترنت فقط برای بررسی به‌روزرسانی استفاده می‌شود.

آیا اطلاعاتی از من جمع‌آوری می‌شود؟

خیر. روزنما هیچ داده شخصی یا آماری جمع‌آوری نمی‌کند. تنظیمات و لاگ‌ها روی دستگاه خودت ذخیره می‌شوند.

چطور بررسی خودکار به‌روزرسانی را خاموش کنم؟

از صفحه تنظیمات برنامه، گزینه بررسی خودکار به‌روزرسانی را غیرفعال کن. در این حالت می‌توانی هر زمان خواستی دستی نسخه جدید را بررسی کنی.

تفاوت نسخه نصبی و پرتابل چیست؟

نسخه نصبی برنامه را برای حساب کاربری ویندوز نصب می‌کند. نسخه پرتابل نیاز به نصب ندارد و تنظیمات و لاگ را در پوشه data کنار فایل اجرایی نگه می‌دارد.

کدام نسخه را دانلود کنم؛ x64 یا x86؟

برای ویندوز ۶۴ بیتی، x64 را انتخاب کن؛ برای ویندوز ۳۲ بیتی، x86 مناسب است.

تاریخ قمری همیشه با تقویم رسمی ایران یکسان است؟

منبع تاریخ قمری از تنظیمات قابل انتخاب است. داده رسمی مرکز تقویم دانشگاه تهران برای سال‌های پوشش‌داده‌شده استفاده می‌شود و برای روزهای خارج از پوشش، ام‌القری جایگزین می‌شود؛ بنابراین ممکن است در برخی روزها اختلاف یک‌روزه وجود داشته باشد.

چرا بعضی مناسبت‌ها تقریبی نمایش داده می‌شوند؟

برای سال‌هایی که داده رسمی قمری در بسته موجود نیست، برخی مناسبت‌ها با قواعد ثابت محاسبه می‌شوند و ممکن است تقریبی باشند.

هنوز سؤالی داری؟ در GitHub یک Issue ثبت کن.
