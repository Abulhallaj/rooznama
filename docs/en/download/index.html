Installer or portable?

  • Installer: the easiest option for everyday use; by default it installs for the current Windows user.
  • Portable: useful when you prefer to run the app from a chosen folder or removable drive; settings and logs are stored beside the app.
  • Requirements: packages are self-contained and do not need a separate .NET or Windows App SDK installation.
  • Updates: recent versions use Velopack for lightweight application updates.
