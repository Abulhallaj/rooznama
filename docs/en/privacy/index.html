PRIVACY

Your information,
stays yours.

Rooznama works offline for everyday use and does not collect personal information or usage statistics.

Information collection

Rooznama does not collect or transmit personal information, usage statistics, behavioral analytics or telemetry.

Internet connection

The calendar, date converter and bundled observances do not require an internet connection for normal use. The app may connect to the internet only to check whether a newer release is available from GitHub. Automatic update checks can be disabled in the app settings; a manual check is also available.

Local files

Application settings and diagnostic logs are stored locally on your device. In an installed setup, app data is stored in the current user's AppData folder. In portable mode, it is stored in the data folder beside the application. These files are not automatically sent to the developer.

Third-party services

When update checking is enabled or manually requested, Rooznama contacts GitHub to read release information. That connection is subject to GitHub's privacy practices. Rooznama does not add personal information or usage statistics to the request.

Changes to this policy

If future versions change network behavior or data handling, this page will be updated accordingly.
